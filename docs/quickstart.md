# Быстрый старт

Основной сценарий: один администратор подключает уже работающий Samba-сервер по SSH.
Панель устанавливается из готового Docker-образа, Nginx предоставляет HTTPS.

## Что подготовить

- Машину с Docker Engine, Docker Compose и Git для получения файлов поставки.
- DNS-имя панели и TLS-сертификат с полной цепочкой и приватным ключом. Браузер должен
  доверять сертификату; имя в URL должно входить в сертификат.
- SSH-адрес и порт Samba-сервера, доступные **из контейнера панели**, и SSH-реквизиты
  администратора по [инструкции подготовки сервера](server-setup.md).
- Публичный SSH-ключ сервера и SHA-256 отпечаток, сверенные через независимый доверенный
  административный канал по [инструкции доверия](ssh-host-keys.md).

JDK, Maven и npm на машине установки не нужны. Установка панели не устанавливает Samba
на удалённом сервере и не меняет его SSH-настройки.

## Установка и первое подключение

1. Получите файлы поставки и подготовьте `.env`, TLS и `known_hosts` по разделу
   [настройки production Compose](production.md#setup). Выберите конкретный
   опубликованный тег образа или digest вместо `latest`.
2. Запустите [панель для существующего сервера](production.md#existing-server)
   и проверьте готовность контейнеров. По умолчанию HTTPS слушает только Docker-хост
   на `127.0.0.1:8443`; доступ с другой машины требует явно выбранного адреса и разрешённого
   сетевого доступа, описанных там же.
3. Откройте HTTPS-адрес панели с `/ui/`. В форме «Подключение к серверу» укажите SSH-хост,
   порт (кнопка «Порт: 22»), пользователя и пароль либо содержимое приватного ключа.
   Это реквизиты Linux/SSH, а не пароль Samba/SMB и не новая учётная запись панели.
   Для ключа используйте поддерживаемый формой ключ без passphrase и защитите его на машине оператора.
4. Нажмите «Подключиться». Успешный вход открывает панель с обзором сервера. Проверьте
   статус Samba и раздел общих папок; пустой список допустим, если ресурсы ещё не созданы.
   Создание первого ресурса выполняйте только после проверки, что подключён нужный сервер.

Адрес браузера и SSH-хост различаются: `localhost` в форме означает контейнер панели,
а не компьютер с браузером. Таблица адресов и разбор отказов находятся в
[production-инструкции](production.md#first-connection).
Неизвестный или изменённый ключ блокирует вход; не принимайте показанный отпечаток без
независимого подтверждения.

Если отдельного Samba-сервера ещё нет, используйте дополнительный
[полный стек с Samba](production.md#bundled-samba).
Для разработки из исходников см. [сборку и поставки](distribution.md) и
[Docker Sandbox](https://github.com/AndreyJVM/sambryx/blob/master/docker/README.md).
